# Testimonials section

Copy these files into the other project:

1. Add `testimonials.html` where the section should appear.
2. Load `testimonials.css` in the page `<head>`.
3. Load `testimonials.js` before `</body>` for the carousel and reveal animation.
4. Copy `assets/testmosni.png` to the new project's `assets` folder. If its location changes, update the image path in `testimonials.css`.

The section is framework-independent and works without any external library.
